# si firda lovely

> **Powered by GIENETIC**  
> Developer: [@Gieneticc](https://t.me/Gieneticc)

Aplikasi Android Root untuk mempermudah menjalankan Frida & script hook tanpa harus selalu membuka terminal Termux secara manual.

---

## ✨ Fitur Utama

- **Theme Adaptif**: Mendukung Dark Mode & Light Mode (otomatis mengikuti sistem atau manual).
- **Auto Check & Install**: Deteksi otomatis root (KernelSU, Magisk, APatch) dan binary `frida-server`. 1-click download & install Frida terbaru langsung dari GitHub Release resmi sesuai ABI device (`arm64-v8a`, dll).
- **Server Controller**: Toggle ON / OFF daemon `frida-server` di background via root shell.
- **Hook Runner**: Input Package Name target + pilih file script JS lokal via file picker, lalu Run.
- **Live Terminal Log**: Console log output stdout & stderr realtime di dalam aplikasi.

---

## 🚀 Cara Build APK via GitHub Actions

1. Clone / upload seluruh folder repo ini ke GitHub kamu.
2. Buka tab **Actions** di repo GitHub.
3. Jalankan workflow **Build APK** (atau otomatis ter-build setiap `git push`).
4. Unduh file APK hasil build di bagian **Artifacts** (`si-firda-lovely-debug`).
5. Install di device Android yang sudah memiliki akses **Root (KSU / Magisk / APatch)**.
